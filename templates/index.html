      About Hansi

      Hansi is the everyday name for HAM-C — Hierarchical Auditable Memory for ChatGPT.

      It is a wrapper around ChatGPT. You chat here instead of on the ChatGPT website. Hansi talks to ChatGPT through an OpenAI API key and shows the replies in this app.

      Memory is handled by Hansi, not by ChatGPT Memory. When you share a lasting detail, Hansi saves it in the Fact store, can reuse it in later chats, and shows which fact was used under the answer.

      If you delete a chat, the facts that came from that chat are removed too — so Hansi will not keep remembering them.

      That makes it easier to see and manage what the assistant knows about you, without needing a separate ChatGPT login.
